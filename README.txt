REQUISITOS

- XAMPP
- Apache
- MySQL
- Navegador web


INSTALACIÓN

1. Instalar XAMPP.

2. Copiar la carpeta sportcustom
   dentro de:

   C:\xampp\htdocs\


3. Abrir XAMPP.

4. Iniciar:

   Apache
   MySQL


5. Abrir phpMyAdmin:

   http://localhost/phpmyadmin/


6. Crear una base de datos llamada:

   sportcustom


7. Seleccionar la base de datos
   sportcustom.

8. Entrar en IMPORTAR.

9. Seleccionar:

   database/sportcustom.sql

10. Pulsar IMPORTAR.


///EJECUTAR EL SISTEMA///

Abrir:

http://localhost/sportcustom/frontend/index.html
